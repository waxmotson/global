      How to play

      Fill the 3×3 grid with first-level subdivisions — states, provinces, regions, prefectures, cantons, emirates… There are thousands to choose from.

      1. Tap a square. Its row and its column each set a rule.
      2. Name a subdivision that satisfies both rules.
      3. You get 10 guesses for 9 squares. Right or wrong, every guess costs one.
      4. Each subdivision can only be placed once.

      When the grid is over, tap any square to see everything that would have fit.

      Daily is the same grid for everyone each day. Practice is unlimited: build a custom board from any six rules, or challenge friends to race you on the same board with a live scoreboard.

      Name rules use the name exactly as the search box shows it. A sea coast means open sea, not a lake or the Caspian. Areas, borders and coastlines are measured from Natural Earth boundaries (public domain); a few countries are grouped up to their true first level (French and Italian regions, UK countries…).
